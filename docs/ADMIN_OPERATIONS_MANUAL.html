1. Admin Portal Navigation Overview

The Admin Console (/admin) allows founders and authorized workshop staff to manage enquiries, track production jobs, generate invoices, publish new products, and configure system settings.

Module Route Key Operations
Dashboard /admin Quick KPI metric cards, recent leads, quick actions.
Enquiries / Leads /admin/enquiries View customer measurements, budget, contact method, assign staff.
Orders & Production /admin/orders Update fabrication stages and send 1-click WhatsApp alerts.
Content Hub & Media /admin/content Upload photos/videos up to 50 files; 3-step verified asset deletion.
Tax Invoices /admin/invoices Issue official GST invoices and payment receipts.
Team Directory /admin/team Manage founder records and internal technician assignments.

2. Dispatching Live WhatsApp Status Alerts

STEP 1 Open /admin/orders.

STEP 2 Locate the customer's active order row.

STEP 3 Click the green "💬 Send WhatsApp Update" button.

STEP 4 WhatsApp opens with pre-formatted professional production copy detailing the Order ID, current stage (e.g. Under Precision Workshop Fabrication), and estimated handover date.

3. Content Publishing & 3-Step Verification Media Deletion

To maintain website asset integrity, image deletion requires strict 3-step authorization:

3-Step Deletion Protocol in /admin/content:
1. Visual Confirmation: Click "🗑️ Delete Asset" to review thumbnail and URL.
2. Risk Acknowledgment: Check the confirmation box acknowledging permanent removal.
3. Security Keyphrase: Type DELETE in capital letters to activate the red destruction button.

4. Security & Access Control Guidelines

  • Role Authorization: SUPER_ADMIN has full rights; ADMIN handles orders and content; STAFF handles daily enquiry follow-ups.
  • Zero Fake Transactions: Dummy payments are disabled; all financial records must tie to real issued invoices.
  • Public Contact Numbers: Keep public contact lines strictly limited to Co-Founders (8795662161 & 7007710096).
